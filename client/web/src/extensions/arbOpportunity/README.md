# 统一套利检测与连线

[changmen 扩展] `@changmen/arb-core` 的 `detectArbLegs` 提供订单构建、机会扫描和 BetRow 共用的选腿快照。底层仍采用原 `pickArbLegs` 规则，保留主侧优先、平台排除、利润范围和账号利润覆盖。

- 同一盘口、同一报价及选腿参数复用同一个快照；每次调用读取报价确认输入，变价、锁盘、选项替换、平台范围或利润设置变化立即重新检测，无时间 TTL。
- 缓存按盘口对象弱引用，每盘最多保留 4 份输入结果；不新增扫描定时器或全局 UI 行情广播。
- BetRow 始终使用账号资金门槛和套利场馆白名单，与订单构建的选腿范围一致；买入开关只控制执行，不切换成全盘口展示。连线只说明扫描选出的组合，不代表预检、选号或实际成交已经成功。
- 机会数据携带两腿的选项 ID；连线及高亮按场馆、方向和选项 ID 定位，不按平台行号猜测。
- 核心检测不依赖 Vue/Pinia/DOM；绘图在 UI 的 animation frame 中合并执行。关闭扩展 UI、缺失锚点或卸载组件不改变检测和下单。

当前快照不包含涨赔归因，也不改变单边下注策略。PM 涨跌角标仍是历史触发快照，不能视为当前套利组合的形成原因。
