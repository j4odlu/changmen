# 当前地图 PM 价格趋势

[changmen 扩展] `PmPriceTrend.vue` 在赛事卡片最后一个盘口之后展示当前 PM LIVE 地图双方的三十分钟走势；普通页面和 listener 复用同一入口。没有明确的 PM 当前地图或缺少双方 token 时不展示，不使用 OB 进度推断。

用户中心 → 界面 → PM 价格趋势：默认关闭，旧用户缺失配置时也关闭。`Extensions.pmPriceTrendUi` 仅为布尔值 `true` 时挂载图表，独立于 BetRow 扩展 UI。开关立即生效，沿用界面页“保存”按钮持久化到用户 Extensions；关闭时卸载组件、释放行情监听及刷新资源，清除无使用者的走势缓存。

- 价格是原始 PM `bestAsk`（可买入价，0–1），以美分展示；两条线分别取双方真实报价，不用互补价格推算。悬停展示采样时间附近的价格和十进制赔率，不含手续费及下注价格缓冲。
- `runtime.ts` 只旁路监听已有 `onPolymarketMarketQuote`，不注册资产、不操作连接、不写业务 store、不导入套利或下单模块。所有图表共用一条监听和一个每秒刷新时钟；赛事卡片只读取用户显示开关。
- `history.ts` 每秒最多四个点，保留首价、最低价、最高价、末价；每个资产最多覆盖三十分钟（最多 1801 个秒桶）。图表使用阶梯线，超过 30 秒没有观察到报价的间隔不连线，超过 30 秒未收到双方新报价标记等待更新。
- 只在组件挂载并找到当前地图时记录；切换地图或卸载释放引用。最后一个使用者释放资产后立即清空该资产缓存；所有图表释放后移除事件监听和定时器。刷新页面、重新挂载不会补历史，没有持久化或额外历史请求。
- 宽 320px，高度对齐最后一个盘口。同排时使用尺寸隔离，图表内容不参与撑高盘口；换行时只读取最后盘口高度，折叠时收起图例/图表以适应高度。尺寸观察随组件卸载释放，样式仅作用于图表。不修改盘口宽度、盘口展示、套利检测、金额分配或 FOK/GTC 执行逻辑。
