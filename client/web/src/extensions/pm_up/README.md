# pm_up

[changmen 扩展] 浏览器内独立检测展示模块，信号来自 changmen 已接收的 PM 行情，不读取第三方 POD，不选号或下单。

在用户中心「界面」Tab 的独立 `pm_up 涨赔信号` 配置区开启并保存；与 `pm_down 降赔信号` 分区显示。默认关闭；默认任意实际涨赔、最小套利利润 1%、观察窗口 5 秒、同方向同场馆冷却 10 秒。开启即同时检测和显示，独立于主套利开关和 PM 降赔浮窗。

- 监听现有 `onPolymarketMarketQuote`，不增加订阅或网络请求，不等待主套利执行。
- 原始 PM 卖一 `bestAsk` 下跌代表十进制赔率 `1 / bestAsk` 上涨。仅新涨价事件触发判定；窗口内最低赔率为涨幅基线，首次报价和长于窗口的行情间隔只建立基线。
- 通过 PM token 索引定位同一合场盘口的规范方向；PM Home 涨赔时读取其他场馆 Away，PM Away 涨赔时读取其他场馆 Home。每个场馆取最高有效赔率，排除锁盘及无效报价。
- 利润口径为 `(1 / (1 / PM赔率 + 1 / 场馆对侧赔率) - 1) * 100`，必须为正且达到配置阈值。PM 使用原始行情，不受展示缓冲设置影响；展示的是报价层理论套利空间，未做可成交深度或下注预检。
- 收到行情时冻结对侧报价，再分批异步计算；同一盘口、PM 方向、目标场馆选项独立冷却。持续未变价不会重复触发，只有场馆变价也不会触发。
- 展示沿用降赔信号的层次：独立浮窗默认收为圆形入口，支持展开、拖动、缩放和清空；对应全场/地图赔率上方显示紧凑信号卡片，默认最多 3 条，可展开。卡片展示历史快照、PM 涨幅、场馆关注方向和套利百分比。最多保留 100 条，关闭、退出页面、换用户或修改参数会重建监测并清空历史；清空按钮仅清除显示记录。

源码：`settings.ts` 配置，`detector.ts` 纯检测器，`markets.ts` 合场映射和报价快照，`runtime.ts` 行情监听与队列，Vue 组件负责生命周期和展示。
