## 确认的缺口与修复

1. **过期错误码不匹配**：前端仅对 ACCESS_TOKEN_EXPIRED 自动续期，后端却把 JWT 过期归并为 AUTH_REQUIRED。后台标签页即使长期 Cookie 仍有效，也可能直接清本地登录态。新增 HTTP 鉴权结果分类，签名、issuer/audience 验证通过后才能标记过期，过期 token 不放行业务；兼容旧后端 AUTH_REQUIRED 的一次续期恢复。
2. **并发/慢响应**：旧请求或旧续期在重新登录/退出后返回，可能清除或恢复错误的会话。增加跨标签页会话版本和本页版本校验；新旧用户的数据响应不混用。即使 storage 事件尚未处理，旧页也不能发出业务请求或退出新会话。
   提交前复查还复现了登录响应尚未返回时的旧会话撤销竞态：增加短期跨标签页登录进行中标记，防止旧鉴权失败中断新登录。标记在成功/失败时清理，并有 60 秒过期兜底。
3. **多标签页令牌轮换**：原单飞刷新只在当前 JS 页面有效，旧 refresh token 缓存在各页内存。通过 Web Locks 串行同源标签页的登录、退出及旧 refresh token 轮换，并在锁内重新读取当前凭证。Cookie 续期不轮换/写入 Cookie，允许各页并发，避免后台页持锁拖住前台页；Cookie 模式依旧不把 access token 写入 localStorage。没有 Web Locks 的环境保留原执行能力，读取最新凭证；严格跨页轮换互斥依赖 Web Locks，生产 HTTPS Chrome 支持此能力。
4. **后台/休眠/断网恢复**：增加 online、focus、pageshow、visibilitychange 恢复续期，30 秒内去重，停止续期时移除监听。保留 10 分钟常规刷新及临时失败重试。
5. **恢复阶段的临时失败**：Cookie 模式还没有内存 access token 时，原 fetchUserInfo 静默返回，恢复页面判断又只认 access token，可能显示空壳。现在保留会话并展示恢复重试；仅有旧 refresh token 时也可恢复。初始化异常纳入恢复错误处理。
6. **数据库故障与退出混淆**：HTTP 会话查询/资料加载暂不可用返回 TEMPORARY_UNAVAILABLE，不清客户端会话，也不在无法验证时执行业务。现有其他 authGetUser 调用方契约保持不变。
7. **失效原因不完整**：增加 ACCESS 拒绝审计（已验证用户/原因每分钟最多一条），补充浏览器会话空闲到期、绝对到期、证书不匹配和撤销原因。审计不保存 token、Cookie 密钥或密码。

## 不变的约束

- 真正的退出、会话撤销、其他设备重新登录引起的撤销和 ACCOUNT_DISABLED 响应仍生效；没有把单会话策略改成多设备无条件共存。
- 同一浏览器同一站点的足球与电竞标签页可同时使用同一用户，无需分别重新登录。跨域名/独立浏览器不是同源共享会话，本次未修改跨域或多设备策略。
- 浏览器会话空闲 8 小时、绝对 7 天的上限和证书绑定维持原值，没有用永久 token 隐藏故障。
- 自动重放只针对明确的 AUTH_REQUIRED/ACCESS_TOKEN_EXPIRED 鉴权拒绝，最多一次；网络失败、超时、5xx 或业务拒绝不自动重放。保存内容、字段和成功请求的次数保持不变。
- 普通续期不触发标签页重载；只有明确登录/退出边界的版本变化才让其他标签页重建用户状态。
