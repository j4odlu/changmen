# PM 插件会话保持（第一阶段）

[changmen 扩展] 只实现 PM 网页钱包的工作会话恢复，不迁移密文仓、不把签名移入插件、不增加快捷解锁。

## 使用与交付

同步部署后端、网页，并重新加载 Chrome 插件 1.3.71。解锁框默认勾选「保持 PM 解锁会话」，未设置期限时默认「直到浏览器退出」，也可选择 1/4/8/24 小时；已有明确保存的固定期限偏好保留。首次解锁后，账号栏显示保持方式或会话到期时间，可「锁定 PM」或关闭会话保持。刷新/关闭再打开标签不会延长固定到期时间，暂停挂机或长时间无人操作不会锁定。浏览器进程重启、插件重载/更新清除会话；关闭全部窗口但浏览器后台进程仍运行，不等同于重启。更改期限选项仅作用于下一次解锁建立的新会话，不延长正在运行的会话。

插件缺失、旧版、不支持真正的 storage.session、身份服务不可用或绑定不匹配时，仍使用密码解锁。关闭功能后可继续使用原有密码流程。导入/改密仍需共享钱包的完整密码解锁。PredictFun 不会通过 PM 缓存获得私钥；如果页面还需要解锁 PF，本来的密码提示仍然存在。

## 边界与协议

- 网页 IndexedDB 继续保存原密文。插件只用 `chrome.storage.session` 保存 PM 私钥集合、到期时间、登录 epoch 和会话 revision；不缓存密码/共享 vault KEK，不降级到 local/sync。
- 独立 `pmWalletSession:restore/save/lock/remove` 协议；旧 `getStore/setStore` 无权访问钱包命名空间。session access level 固定为 TRUSTED_CONTEXTS，内容脚本不开放。`expiresAt=-1` 表示跟随浏览器会话，`0` 表示锁定/空会话，正数为绝对到期时间；`hours=0` 请求浏览器会话，非法期限拒绝保存。
- 仅允许顶层 `https://changmen.fun` 页面，以及 localhost/127.0.0.1 的当前配置开发端口（`VITE_DEV_PORT`）。生产身份请求固定访问 `https://api.changmen.fun/auth/pm-wallet-identity`，与网页登录 Cookie 的主机一致；开发访问网页同源 `/auth/pm-wallet-identity`，沿用 Vite 的 `/auth` 代理配置，不在插件内硬编码后端端口。API 地址不允许网页消息覆盖。缺少登录凭证与明确会话撤销分开提示；核验失败不返回私钥，只有明确撤销才清空插件缓存。构建插件时复用 `server/storage/dev_web_config.js`，读取 `client/web/.env*` 的 development 配置，进程环境变量优先；未配置时使用该共享模块的平台默认值。修改开发端口后重建并重新加载插件，无需修改源码。其他预览站点不启用保持，使用密码回退；网页明确显示地址未授权、插件不支持或身份核验失败的原因。
- 插件自行请求固定后端 `/auth/pm-wallet-identity`，验证 Cookie/JWT、登录 epoch、归属和 PM 钱包地址。该只读接口响应 no-store，仅返回身份和账号/地址，不接收私钥、不返回账号 token。
- 读取本机密文及 meta 的完整绑定，防止清网站数据、替换密文后恢复旧钥。不同站点/开发环境、用户、登录 epoch 不复用缓存。
- 密码解锁前获取插件 revision，保存时必须匹配；锁定/到期后 revision 改变，旧异步写不能恢复会话。撤销句柄只具有清空权限，允许后端登出后清空；网页 localStorage 只存偏好和这种不可用于恢复的撤销句柄。
- 页面卸载仅清本页内存；主动退出/登录切换、手动锁定、改密撤销整个 PM 会话。删除 PM 账号、替换私钥只撤销对应账号旧钥，保留其他账号；撤销操作不返回私钥，更新 revision 阻止旧保存重新写入。其他标签通过同源 storage 事件即时清理，并每 15 秒核验插件状态。明确登录撤销/身份变化、插件会话锁定/到期才清理；网络超时、后端 503、访问令牌等待续期和插件暂不可达保留已经解锁的本页钥并重试，同时显示状态提示。身份未核验成功时不向新页面返回私钥。
- 固定期限模式有独立的绝对到期定时器，读取恢复钥时也检查时间；浏览器会话模式不创建到期定时器。锁定清除 PM token、共享 vault 内对应 PM 条目和 CLOB signer 缓存，保留 PF 条目。已经签出或已经发送的订单不能被钱包锁定撤销。
- 插件新增 alarms 权限，固定期限到期唤醒后台清除会话材料（没有打开网页也执行）；浏览器会话模式不创建到期 alarm。浏览器休眠可能推迟 alarm，恢复/保存时仍按绝对时间拒绝过期会话。
- 会话保存串行执行并保留调用时的私钥快照，旧保存响应不能覆盖后续更新；私钥替换会撤销旧钥后再写入本机密文仓。
- 主动锁定先清本页钥，并在 localStorage 保存不含私钥的待撤销标记。插件未确认时禁止恢复/保存会话，跨刷新保留阻断，显示撤销待确认状态并每 15 秒重试；可手动「重试锁定」。收到匹配本次请求的成功确认后才移除标记，旧确认不能清除更新的锁定请求。关闭保持时同样处理撤销失败。其他标签同步开启/关闭及固定期限偏好，重新开启不自动解锁。
- 合并账号内存 token 时同时核对用户、账号 ID 和 PM 钱包地址，地址变化不能注入旧地址的恢复钥；完整钱包会话也保留密文记录中的账号地址绑定。历史未记录地址的密文保持原有按 ID 解锁行为。
- [changmen 扩展] 恢复资格以每个账号最新的钱包地址为准，旧对象引用仅用于锁定清理；就绪判断和待解锁提示同样检查地址。密码解锁完成后再次检查当前账号是否取得匹配的钥，地址不匹配仍返回不可用。移除账号（含其他标签通知）会重新安排剩余账号的定期校验，避免丢弃旧请求后停止核验。

## 验证

自动测试覆盖来源/iframe/其他扩展拒绝、身份伪造、账号归属变化、登录 epoch 切换、worker 重启、超时/旧插件、锁定写入竞态、到期清钥、PM/PF 隔离、共享 vault 完整解锁不被伪造，以及接口凭证剥离。

真实 Chrome 手动验收：首次解锁→刷新→新标签恢复；在一个标签锁定，另一个停止新签名；退出后重新登录需要解锁；重载插件需要解锁；关闭保持后恢复原行为；导入/改密和 PF 密码行为不变。不需要执行真实下注，可用状态与预检验证。

第一阶段解锁后的网页仍持有 PM 私钥。浏览器会话模式下，长期运行意味着解锁私钥在内存中长期可用，用户需持续信任电脑、插件和网页。插件与授权网页的恶意脚本、浏览器调试权限仍在信任边界内；本阶段不承诺系统凭据库或硬件钱包级别的保护。
