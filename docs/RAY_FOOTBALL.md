# RAY 足球跟单

[changmen 扩展] RAY 足球使用独立足球列表及 `sportOddsStore`，支持足球板双击手动下单和 POD 信号自动跟单，不进入电竞自动投注循环。

## 使用

1. 足球设置 → POD → 选择 RAY 投注账号，设置 RAY 金额、每日单数上限。
2. 手动：双击 RAY 赔率格确认本次金额，或在 POD 浮窗点击“下RAY”。
3. 自动：打开现有“自动下注”。RAY 只执行身份已确认、有实时赔率且满足筛选、EV 和风控条件的信号。默认 RAY 金额为 0，账号为空，不会自动启用。

金额按人民币配置，沿用账号预检的场馆币种换算。每个已选 RAY 账号各下一注。下单使用所选账号凭证，采集凭证只用于赛事和赔率读取。

## 提交与订单

[changmen 扩展] 自动提交之前，通过 `Client_ReservePodBet` 获取 RDS 执行权，按用户、信号、场馆和账号去重。封盘和限额由 RAY 预检检查；返回赔率还会重新校验策略 EV 上下限。

RAY 提交接口不直接返回订单号。提交前保存场馆订单 ID 快照，提交后按新订单 ID、创建时间、比赛、盘口、选项、金额精确匹配。只有唯一候选才绑定；歧义保留待确认状态，禁止自动重试。

本机 `changmen:ray-football-bind:v1:<用户>` 仅保存待回查任务，不含账号凭证。页面恢复后继续回查。正式订单通过 `Client_SaveOrder` 保存到 RDS `orders`，附带 `domain=sports`、`sport=football`、POD 信号和 RAY 赛事/盘口/方向字段。足球页每 15 秒回查绑定和场馆结算；订单显示在统一订单栏。无法确认的提交保留敞口并阻止同票重试。

## 发布

需要同时发布前端和后端。`npm run db:apply --workspace=@changmen/backend` 包含 `045_pod_ray_execution.sql`，扩展执行权表 RAY 约束。运行时首次申请执行权也会兼容更新该约束。

代码验证使用模拟接口，不提交真实投注。正式场馆受理、延迟拒单及结算的实单验收尚未进行。
