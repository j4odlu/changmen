## 实现范围和边界

### 独立完整读簿

- `BookStore.fullBook()` 提供完整双边深度，保留原始十进制字符串、源时间、单调接收/快照时间、内部 generation/revision；不使用展示接口的 20/50 档截断。仍受核心每侧 2,000 档等原有上限约束，超限不冒充完整。
- 公共 `BookLease.readFullBook()` / `isCurrent()` 是只读能力，不拥有连接、订阅、重连、HTTP 或交易权限。展示与完整读取共用最多 32 个在途额度；租约释放、断线、资产变化、失效和服务停止会结清读取。
- 完整读取预算为 20ms，覆盖主线程排队和 Worker 往返。Worker 在处理过期请求前返回超时，主线程接收回复时也按实际单调经过时间复核，不能因后台 timer 延迟而接受旧结果。数据不使用 Worker 出队时间重新打时间戳。
- 响应带已处理的本地输入位置；主线程若已接到更晚的帧，返回 `stream_advanced`。这是一条保守保护，会牺牲命中率；本轮不通过放宽它或消息年龄提高结果。该位置不是交易所连续序号，不能证明上游不存在静默遗漏。
- Worker 无条件通知本地簿失效，撤销已发出的视图与在途读；主线程以 WeakMap 验证视图确由当前租约发出，伪造/跨租约/跨代次视图不能通过 `isCurrent()`。服务仍独立管理生命周期，动态消费者卸载不停止公共簿。

### 等价计算与实际 HTTP 保真

- 只在 `preflightMode === "optimized"` 的 FOK 调用处附加本次已冻结的 token、限价、金额、检测赔率和深度倍数；经典分支不读取新偏好或创建模拟资源。另两个接入点为可选类型字段和原观察钩子参数。现有 `tasks.market()` 的一次调用、返回和异常处理未改变。
- `executionMath.ts` 是只用于诊断的计算副本，回归逐字检查原有价格/限价/深度函数体，使用相同份数编码函数和原深度函数的显式参数。没有移动、改写原 FOK 计算函数，也没有写全局深度偏好。副本差异必须被测试发现，不可自行演化成另一套交易算法。
- 模拟包含完整读簿、新鲜度/身份/元数据校验、冻结限价、金额、最小份数、tick、深度倍数、限价取整、签单份数与返回字段计算。源时间 ≤5s、不超前 1s、接收年龄 ≤1s、快照和元数据 ≤60s 等仍是 changmen 策略，不是已证明适合实际交易的官方门槛。
- 当前元数据沿用动态消费者的经过校验的 HTTP probe 缓存；在本次 HTTP 开始前冻结，不允许用本轮 HTTP 成功结果反过来“证明本轮本地命中”。缺元数据立即模拟 HTTP 回退。公共订单簿不负责这些签单元数据。
- `simulateLocalSource()` 只能返回诊断对象，接口不接受 HTTP、签名器或下单回调；生产仍无执行源切换分支。现有 local-book/shadow 两个开关只控制订单簿与诊断，不能升级成真实执行授权。

`local_candidate` 只表示这个盘口来源满足本地读取与计算条件，不表示整组预检或下单获准。赛事终局、锁盘/最新不利报价、账号绑定、取消、钱包及提交前检查继续由原实际预检执行，模拟不复制或替代这些保护。

### 异常回退模拟

本地成功只标记 `local_candidate`；数据不完整、过期、元数据未知、读取超时、处理位置变化、tick 不支持、计算拒绝或错误标记 `http_fallback`；退出/作用域变化标记取消。回退模拟复用本轮原 HTTP 的成功或失败观察，记录 `fallbackResult`，**不会再发送一份 HTTP，也不能把本地成功替代 HTTP 失败**。HTTP 成功对象原样返回，异常原样抛出。

迟到本地回复和停止后的回复不能成为候选；迟到 Worker 读回复找不到挂起请求即丢弃。可对齐的计算差异会锁住该消费者后续本地模拟候选，直到新的授权消费者作用域；不会修改 PM-M 或自动启用第二个 WS。未对齐/同时间戳歧义不计为一致性通过。

注意：本轮验证的是“如果优先本地，该次应使用哪一来源”的影子状态机。实际 HTTP 从原时间点发起，因此回退观察耗时不是未来“先等本地 20ms 再发 HTTP”的实测耗时；未来真实执行仍须接入受限来源选择器并单独复审，不得把本轮模拟对象直接返回给下单。
